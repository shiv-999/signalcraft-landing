# Signalcraft — SaaS landing page

A landing page for a fictional AI marketing product, built to show how I approach a modern marketing site.

**Live demo:** https://shiv-999.github.io/signalcraft-landing/

## What's in it

- Next.js (App Router) with TypeScript and Tailwind CSS
- Static export, so it can be hosted anywhere (GitHub Pages here, Vercel works too)
- Interactive pieces: mobile menu, monthly/yearly pricing toggle, FAQ accordion, waitlist form with client-side validation
- SEO basics: metadata, Open Graph, canonical URL, sitemap.xml, robots.txt and FAQ structured data (JSON-LD)
- Accessible markup: semantic sections, labelled controls, visible focus states, reduced-motion support

Signalcraft is not a real company, and the signup form does not send any data.

## Run locally

```bash
npm install
npm run dev
npm run lint
npm run build   # static site in out/
```
